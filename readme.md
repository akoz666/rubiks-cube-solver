# Flowline Rubik's Cube Solver

A Rubik's Cube solver web app, built with [Vite](https://vite.dev) (vanilla JS).

## Getting started

```bash
npm install
npm run dev
```

The dev server starts on `http://localhost:5173`.

## Build

```bash
npm run build
```

## Project structure

```
src/
  cube/     # cube state and model logic
  solver/   # solving algorithm
  ui/       # rendering and interaction
  assets/   # static assets
```
